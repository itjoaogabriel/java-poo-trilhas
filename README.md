# Estudos de Java — Sintaxe e POO

Repositório que reúne meus estudos iniciais de Java e as trilhas práticas de Programação Orientada a Objetos.

Os primeiros arquivos correspondem à fase de adaptação à sintaxe do Java, com exercícios de variáveis, operadores, 
condicionais, estruturas de repetição, arrays e primeiros contatos com classes. Depois, o estudo passou a ser 
organizado em oito trilhas práticas de POO, com atividades e desafios.

## Organização do repositório

- `src/com/joao/cursojava/` — estudos iniciais de sintaxe e lógica em Java.
- `src/com/joaotrilhas/` — atividades e desafios organizados nas Trilhas 1 a 8 de Programação Orientada a Objetos.
